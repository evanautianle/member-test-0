# Very Legit Club – Payload CMS + Next.js Prototype

A prototype membership site using Payload CMS, Next.js, MongoDB Atlas, and Stripe. Demonstrates a CMS-first approach with auto-generated admin, custom signup, and payment integration.

## Features

- **Members Collection**: name, email, student_id, payment_status
- **Signup Form**: Users sign up; data is stored in MongoDB via Payload API
- **Stripe Payments**: Signup triggers Stripe Checkout; webhook updates payment_status
- **Admin Panel**: Auto-generated by Payload CMS for easy CRUD
- **Authentication**: Admins managed via Payload’s Users collection
- **Deployment**: Designed for Vercel (frontend + Payload serverless)

## Stack

- Next.js (App Router, TypeScript)
- Payload CMS (headless, admin UI)
- MongoDB Atlas (database)
- Stripe (payments)
- Tailwind CSS (planned, not yet implemented)

## How It Works

1. **Signup**: User submits name, email, student ID.
2. **Member Creation**: If not already a member, creates a new member with `payment_status: pending`.
3. **Stripe Checkout**: User is redirected to Stripe for payment.
4. **Webhook**: On payment success, Stripe webhook updates `payment_status` to `paid`.
5. **Admin**: Admins manage members via Payload’s admin panel.
